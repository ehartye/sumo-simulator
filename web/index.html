Programming this build

Ports: A left motor, B right motor, C downward color sensor, D ultrasonic eyes. Use CLOCKWISE on A and COUNTERCLOCKWISE on B for forward motion. Programs run in separate Python processes with a shared simulation clock. This initial runner supports synchronous Pybricks methods; async tasks and DriveBase are not implemented. See README for the exact API and assumptions.

Edit or load trusted local Python only. Reset applies changes. Drag the ring to orbit; scroll to zoom. Pause and scrub to inspect a recorded frame, then return to the latest frame before continuing.

THE REFERENCE ROBOT

Every part accounted for.

Hub + battery, two medium angular motors, two 56 mm wheels, ultrasonic eyes, one color sensor and a small beam-and-caster frame.

What the model can tell you

Gravity, wheel slip, torque-limited drive, pushing, tipping and contact outside a raised ring are simulated in 3D. Geometry is from LDraw; masses are catalog estimates.

What still needs measurement

Tire friction, battery sag, controller response, sensor noise and internal mass distribution are approximations. Connector fit and chassis stiffness have not been verified on a physical assembly. Match outcomes are exploratory, not validated hardware predictions.
